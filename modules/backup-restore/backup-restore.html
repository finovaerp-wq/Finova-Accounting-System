Buat Backup

Mengunduh snapshot JSON dari tabel perusahaan yang dapat diakses. Jika satu tabel gagal dibaca, proses dibatalkan.

Pemeriksaan File Pemulihan

Periksa struktur, checksum, dan identitas perusahaan sebelum pemulihan. Penulisan ke database belum diaktifkan sampai backend pemulihan transaksional tersedia.

Pratinjau Dampak Pemulihan

Bandingkan ID dan nilai data backup dengan database perusahaan aktif, serta periksa sebagian relasi. Hanya membaca database; tidak menjalankan pemulihan.

Lihat Isi Backup

Pilih file backup JSON, periksa file, lalu lihat dan cari data per tabel. Tidak ada data yang dikirim ke database.

Detail Data Backup
Backup ini merupakan ekspor data tabel yang terdaftar, bukan backup PostgreSQL menyeluruh (skema, Auth, Storage, dan objek database tidak termasuk). Simpan file di lokasi aman; file mungkin mengandung informasi keuangan sensitif.
